# Модуль Messaging (SMS повідомлення) для OkayCMS

Модуль надсилає клієнтам SMS про доставку Новою Поштою, Укрпоштою та Meest. Повідомлення відправляються через TurboSMS або SMS Club автоматично (коли працює планувальник задач OkayCMS).

> Статуси посилок модуль бере з модулів доставки. Для Нової Пошти це **Нова Пошта** (`devSviat/NovaPoshta-OkayCMS`, у OkayCMS це `Sviat/NovaPoshta`) або старий **`Sviat/NovaPoshtaTracking`** (`devSviat/NovaPoshtaTracking-OkayCMS`). Для Укрпошти потрібен модуль `Sviat/Ukrposhta`, для Meest модуль [Meest](https://github.com/devSviat/Meest-OkayCMS) (`Sviat/Meest`). Обидва необов'язкові: якщо модуля немає або він вимкнений, SMS для цього перевізника просто не надсилаються.

## Можливості

### SMS про доставку

Можна окремо увімкнути/вимкнути кожне повідомлення:

- **Замовлення відправлено** — коли посилка “в дорозі”.
- **Прибуло у відділення / поштомат** — коли посилка приїхала.
- **Нагадування через 48 год** — тільки для **наложки**; якщо посилка прибула і пройшло 48 годин.
- **Завтра платне зберігання** — для **наложки** або замовлень **від 1000 грн**; на 6-й день після прибуття. Це повідомлення є лише для Нової Пошти.

У SMS для Укрпошти стоїть номер відправлення. Повідомлення про відправку додає посилання на відстеження на сайті Укрпошти.

Для Meest є два повідомлення: «відправлено» з номером посилки й посиланням на відстеження та «прибуло в пункт видачі». Нагадування через 48 год для Meest немає, бо посилки Meest оформлюються без післяплати, а попередження про платне зберігання є лише для Нової Пошти.

### Підтримка провайдерів

- **TurboSMS** — потрібні токен і ім’я відправника (в адмінці також показується баланс).
- **SMS Club** — потрібні Bearer токен і ім’я відправника (в адмінці також показується баланс).

### Контроль відправки SMS

- Модуль веде **журнал SMS** (що відправилось, що з помилкою, що пропущено).
- Є **захист від частих SMS**: на один номер — не частіше ніж раз на годину.
- Якщо сталася помилка — модуль **спробує ще раз** (до 3 спроб).

## Вимоги

- PHP 8.5+
- OkayCMS 4.5.3 (чиста або [форк](https://github.com/devSviat/OkayCMS-Fork))
- Перевірено на PHP 8.5 — на чистій OkayCMS 4.5.3 і на форку
- Встановлений та налаштований модуль **`Sviat/NovaPoshta`** (`devSviat/NovaPoshta-OkayCMS`) або старий **`Sviat/NovaPoshtaTracking`** (`devSviat/NovaPoshtaTracking-OkayCMS`), чи модуль `Sviat/Ukrposhta` для Укрпошти, чи модуль `Sviat/Meest` для Meest (сам модуль Meest перевірено лише на форку)
- Аккаунт у **TurboSMS** або **SMS Club**
- Для автоматичної роботи — має бути налаштований планувальник задач OkayCMS (scheduler/cron)

## Встановлення

### Варіант 1: Скачування з GitHub

1. Скачайте останню версію модуля з [останнього релізу на GitHub](https://github.com/devSviat/Messaging-OkayCMS/releases/latest).
2. Розпакуйте архів на сервері в каталог: `{OkayCMS_root}/Okay/Modules/`

### Варіант 2: Встановлення через Git

1. Виконайте команду в директорії `{OkayCMS_root}/Okay/Modules/Sviat`:
   ```bash
   git clone https://github.com/devSviat/Messaging-OkayCMS.git Messaging
   ```

### Результат встановлення

Шлях до модуля має бути таким:
```bash
{OkayCMS_root}/Okay/Modules/Sviat/Messaging/
```

Після встановлення перейдіть в адмін-панель → Модулі → Знайдіть «Messaging (SMS повідомлення)» → Натисніть «Встановити».

## Налаштування

1. Перейдіть в адмін-панель → Модулі → **SMS / Повідомлення (Нова Пошта, Укрпошта, Meest)**.
2. В блоці **Провайдер SMS** оберіть провайдера і заповніть дані доступу:
   - **TurboSMS**: токен і ім’я відправника
   - **SMS Club**: Bearer токен і ім’я відправника

   Збережений токен у форму не повертається. Порожнє поле лишає його без змін, а стерти токен можна галочкою «Видалити збережений токен».
3. Увімкніть потрібні типи SMS:
   - ✅ Замовлення відправлено
   - ✅ Прибуло у відділення
   - ✅ Нагадування через 48 год
   - ✅ Завтра платне зберігання
4. Натисніть «Застосувати».

## Використання

### Як відправляються SMS

- Модуль бере **статуси накладних Нової Пошти** з `Sviat/NovaPoshta` або старого `Sviat/NovaPoshtaTracking`. Поки встановлені обидва, накладні беруться з обох; якщо накладна замовлення є в обох — з нового.
- Статуси відправлень Укрпошти модуль бере з `Sviat/Ukrposhta`, а статуси посилок Meest з `Sviat/Meest`, коли відповідний модуль встановлений і ввімкнений.
- Якщо в замовлення є відправлення кількох перевізників, SMS іде за тим, чиїм способом доставки зараз оформлене замовлення. Завершене відправлення (отримане чи повернене) поступається незавершеному. Коли замовлення переводять на іншого перевізника, його відправлення отримує власні SMS.
- Нагадування «заберіть, післяплата» йде для замовлень з післяплатою: з модулем `Sviat/NovaPoshta` — для будь-якої (контроль оплати чи грошовий переказ), зі старим — для контролю оплати.
- Коли статус змінився — модуль відправляє SMS (якщо цей тип SMS увімкнений).

### Автоматична робота (крон/планувальник)

Модуль працює через планувальник задач OkayCMS:

- відправка SMS — приблизно **раз на 20 хв**
- повтор при помилках — приблизно **раз на 15 хв**

Якщо планувальник не налаштований — SMS не будуть відправлятися автоматично.

## Важливо

- Якщо жоден із модулів `Sviat/NovaPoshta`, `Sviat/NovaPoshtaTracking`, `Sviat/Ukrposhta` і `Sviat/Meest` **не встановлений або всі вимкнені**, SMS про доставку **не будуть відправлятися**.
- Модуль може **пропустити** повідомлення, якщо на цей номер уже була SMS протягом останньої години (захист від спаму).
